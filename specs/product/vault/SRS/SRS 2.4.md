# 2.4 Operating Environment

- Web UI accessible via modern evergreen browsers (Chrome, Firefox, Edge, Safari).
- Deployed via Docker Compose for the Demo/QA environment: UI on port 8090, API on port 8080.
- Backend: Ruby on Rails application server with PostgreSQL persistence (implementation detail, not user-facing).
- Responsive layout supports desktop-first usage; tablet support is best-effort.
