# 1.2 Scope

The scope of this document covers end-user and administrator interactions with the following modules, exposed via both the web UI (http://localhost:8090) and the REST API (http://localhost:8080, documented at /api/docs):

- [[Project|Projects]] — creation, configuration, hierarchy, archiving, identifiers.
- [[WorkPackage|Work Packages]] — creation, editing, [[Workflow|workflow]]/status transitions, types, relations, [[Attachment|attachments]], filtering.
- [[Board|Boards]] — Basic and [[Action Board|Action boards]], columns/lists, [[Card|cards]], drag-and-drop, board lifecycle.
- [[Member|Members]] & [[Role|Roles]] — inviting members, assigning roles, permission enforcement, role-based visibility.

Out of scope: Timelines/Gantt charts, Wiki, Cost reports, Notifications/Email digests, Backlogs/Agile points, and system-wide Administration settings (LDAP, custom fields configuration, workflow configuration) are not covered by this revision.
