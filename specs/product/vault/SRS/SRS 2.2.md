# 2.2 Product Functions (Summary)

- Create and manage [[Project|Projects]], including sub-project hierarchies and archiving.
- Create, classify, and progress [[WorkPackage|Work Packages]] through configurable status workflows.
- Visualize and manipulate Work Packages via drag-and-drop [[Board|Boards]].
- Manage [[Member|Members]] and their [[Role|Roles]]/permissions per Project.
- Filter, sort, and search across Work Packages and Boards.
- Expose equivalent capabilities via REST API for automation/integration.
