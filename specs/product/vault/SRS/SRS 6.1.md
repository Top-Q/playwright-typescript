# 6.1 Description

[[Board|Boards]] provide a Kanban-style visualization of [[WorkPackage|Work Packages]], organized into columns ('lists'). OpenProject supports two Board types: 'Basic' (free-form, user-defined lists, [[Card|cards]] added manually) and '[[Action Board|Action board]]' (Status- or Version-backed columns, where moving a card updates the underlying Work Package attribute).
