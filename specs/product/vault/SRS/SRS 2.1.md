# 2.1 Product Perspective

OpenProject is a self-hosted, open-source project management web application. It is organized around [[Project|Projects]], each of which contains [[WorkPackage|Work Packages]], [[Board|Boards]], [[Member|Members]], and other modules. The system enforces role-based access control (RBAC) at the project level, and each module exposes both a browser-based UI and a versioned JSON:API-style REST API.
