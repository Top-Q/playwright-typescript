# 7.1 Description

[[Member|Members]] represent users (or groups) associated with a [[Project]]. Each Member holds one or more [[Role|Roles]], which define the set of permissions granted within that Project. Role definitions themselves may be global (system-wide templates) while assignments are always project-scoped.
