# 1.1 Purpose

This Software Requirements Specification (SRS) defines the functional and non-functional requirements for the core project-management capabilities of OpenProject: [[Project|Projects]], [[WorkPackage|Work Packages]], [[Board|Boards]], and [[Member|Members]] & [[Role|Roles]]. It serves as the authoritative source for deriving manual and automated (Playwright) test cases for the [[Demo Project]] environment.
