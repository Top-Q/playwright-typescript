# 5.1 Description

A [[WorkPackage|Work Package]] (WP) is the atomic unit of trackable work within a [[Project]]. Each WP has a Type (e.g., Task, Milestone, Bug, Feature, Phase), a Status governed by a configurable [[Workflow|workflow]], and a rich set of attributes (assignee, dates, priority, description, [[Attachment|attachments]], relations).
