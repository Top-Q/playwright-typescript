## Preconditions

- User has zero Project memberships and no Administrator flag
- At least one private Project exists that the user is not a member of

## Steps

1. Open the Project switcher
2. Attempt to search for the private Project's name or navigate to its URL/identifier directly

## Expected result

The private Project does not appear in the switcher and is not accessible/discoverable via direct navigation.
