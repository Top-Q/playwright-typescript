## Preconditions

- Work Package A is open and has a 'blocks' relation to Work Package B ^a-blocks-b
- B is in a Status from which the workflow allows a transition to 'Closed'

## Steps

1. Open Work Package B
2. Open the Status selector

## Expected result

No closed Status (such as 'Closed') is offered and B's Status is unchanged. Setting a closed Status on B through the API is rejected as an invalid status transition.
