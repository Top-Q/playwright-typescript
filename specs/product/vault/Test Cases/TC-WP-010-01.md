## Preconditions

- Work Packages exist with varying Status and Type values

## Steps

1. Open the Work Packages list
2. Apply filter Status='New'
3. Apply filter Type='Task'

## Expected result

Only Work Packages that are both Status='New' AND Type='Task' are shown.
