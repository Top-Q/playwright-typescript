## Preconditions

- Multiple Work Packages exist in Status 'New', user has edit permission on all of them

## Steps

1. Select multiple Work Packages in list view
2. Choose bulk 'Change Status' to 'In Progress'
3. Confirm

## Expected result

All selected Work Packages update to Status 'In Progress'.
