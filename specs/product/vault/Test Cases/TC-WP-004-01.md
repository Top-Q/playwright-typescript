## Preconditions

- A Task-type Work Package exists in Status 'New'
- The logged-in user is the Work Package's Assignee

## Steps

1. Open the Work Package detail view
2. Open the Status selector
3. Select 'In Progress'
4. Save

## Expected result

Status updates to 'In Progress' and the transition is recorded in the Activity tab (see [[FR-WP-009]]).
