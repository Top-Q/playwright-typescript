## Preconditions

- Work Package A's only child Work Packages are all in Status 'Closed'

## Steps

1. Open Work Package A and choose Delete from its menu
2. Try to confirm the deletion without ticking the acknowledgement

## Expected result

The dialog asks for the same acknowledgement as for open children, and Delete stays disabled until it is ticked. The children's status makes no difference.
