## Preconditions

- A Project exists with a saved Identifier

## Steps

1. Open Project settings -> Information and follow 'Change identifier'
2. Replace the Identifier with a different valid, unused slug
3. Click Update

## Expected result

The Identifier is updated; the system redirects to /projects/\<new-identifier>/settings/general and the Project is addressed by the new slug thereafter. The previous slug no longer resolves.
