## Preconditions

- Target user already has an account

## Steps

1. Open Members page
2. Click 'Add member'
3. Search for the existing user by name/email/username
4. Select a Role
5. Click Add

## Expected result

User appears in the Members list with the selected Role and Status 'Active'.
