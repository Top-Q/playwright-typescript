## Preconditions

- A Task-type Work Package exists in Status 'New'
- Logged in as its Assignee

## Steps

1. Open the Status selector on the Work Package
2. Look for 'Closed' as an option
3. If present, select it and Save

## Expected result

Per the representative workflow ([[SRS 5.4|Sec 5.4]]), 'Closed' is not a direct target from 'New'; the selector should only list 'In Progress' or 'Rejected'. NOTE: source doc's own acceptance criteria ([[SRS 5.6|Sec 5.6]]) is ambiguous here ('either allows it if the workflow permits or shows only valid transitions') — flag to stakeholder to confirm expected behavior before finalizing this test's pass criteria.
