## Preconditions

- A bulk selection includes one Work Package the current user lacks edit permission for (e.g. not Assignee/Author/no edit permission), and others they can edit

## Steps

1. Select the mixed set of Work Packages
2. Trigger a bulk Status change
3. Confirm

## Expected result

Permitted Work Packages update successfully; the unauthorized item is skipped/reported as failed rather than silently updated or blocking the whole batch.
