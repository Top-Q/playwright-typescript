## Preconditions

- The Project Manager is not an Administrator

## Steps

1. Attempt to access global Role management via UI and API

## Expected result

Access is blocked/hidden in the UI; API request is rejected with HTTP 403.

## Notes

Global Role management has no row in the project-scoped RBAC matrix; enforced as Administrator-only per Section [[SRS 2.3|2.3]], consistent with the note on [[FR-MEM-007]].yaml.
