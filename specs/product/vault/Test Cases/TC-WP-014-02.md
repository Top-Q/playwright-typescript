## Preconditions

- A Task-type Work Package exists with both Start Date and Due Date set

## Steps

1. Open the Work Package
2. Change Type from 'Task' to 'Milestone'

## Expected result

A confirmation prompt warns that the date range will be replaced by a single date; upon confirmation, the Work Package retains only one Date field, with the prior range collapsed per [[BR-WP-02]].
