## Preconditions

- A Project exists with identifier 'demo-project'
- A second Project exists whose Identifier is to be changed

## Steps

1. Open the second Project's 'Change identifier' form
2. Replace the Identifier with 'demo-project'
3. Click Update

## Expected result

The change is rejected with a validation error stating the Identifier has already been taken; the Project keeps its previous Identifier.
