## Preconditions

- An active Project exists
- The Project Manager manages that Project

## Steps

1. Archive the Project
2. Return to the default Projects list
3. Explicitly filter to show archived Projects

## Expected result

Project no longer appears in the default list, but is visible when explicitly filtering for archived Projects.
