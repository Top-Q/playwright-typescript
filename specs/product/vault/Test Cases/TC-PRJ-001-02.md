## Preconditions

- A Project exists with a saved, auto-generated Identifier

## Steps

1. Open Project settings -> Information and follow 'Change identifier'
2. Replace the auto-generated Identifier with a different valid slug
3. Click Update

## Expected result

The Identifier is updated; the system redirects to /projects/\<new-identifier>/settings/general and the Project is addressed by the new slug thereafter.
