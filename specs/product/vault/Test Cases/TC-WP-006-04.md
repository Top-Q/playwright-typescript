## Preconditions

- A Work Package is assigned to User A
- User B is neither the Assignee nor the Author, and holds no 'edit work packages' permission

## Steps

1. Open the Work Package as User B
2. Attempt to change the Assignee field

## Expected result

The Assignee field is read-only for User B, or the change is rejected with a permission error.
