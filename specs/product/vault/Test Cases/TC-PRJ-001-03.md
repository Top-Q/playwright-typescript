## Preconditions

- Logged in as a user with only a Member/Team-Member role, no manage-capable role on any project

## Steps

1. Attempt to access 'New Project' in the UI
2. Attempt the equivalent create call via the REST API

## Expected result

The create control is not shown/enabled in the UI; the API call is rejected with HTTP 403.
