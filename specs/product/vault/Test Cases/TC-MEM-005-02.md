## Preconditions

- A Work Package is assigned to a Member who is then removed from the Project

## Steps

1. Remove the Member
2. Open the previously assigned Work Package

## Expected result

The Work Package still displays the former member's name as Assignee, annotated with an 'inactive/removed' indicator, rather than being blanked or reassigned.
