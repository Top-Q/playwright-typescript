## Preconditions


## Steps

1. Navigate to 'New Project'
2. Enter a unique Name
3. Click Create
4. Observe the Identifier of the created Project

## Expected result

The Project is created and the system navigates to /projects/\<identifier>, where Identifier is a slug derived from the Name (lower case, spaces replaced by hyphens). The same value is pre-filled on the Project's 'Change identifier' page.
