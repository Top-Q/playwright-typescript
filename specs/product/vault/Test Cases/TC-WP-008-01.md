## Preconditions

- Two Work Packages (A and B) exist in the same or different Projects the user can access

## Steps

1. Open Work Package A
2. Add a relation of type 'blocks' targeting Work Package B

## Expected result

Work Package A displays 'blocks' -> B, and Work Package B's detail view displays 'blocked by' -> A.
