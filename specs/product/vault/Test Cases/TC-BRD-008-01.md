## Steps

1. Attempt to create a Board, delete a Board, and rename a list, via UI and API

## Expected result

In the UI, no 'Create Board' control is offered, the Boards list offers no Delete, and list titles are not editable. Via the API, creating a Board is rejected with HTTP 422, deleting one with HTTP 404, and renaming a list with HTTP 403.

## Evidence

Checked 2026-10-08 against OpenProject 16 (Rails source `stable/16`, v16.6.10), source only:

- The Viewer maps to the Reader Role, which holds `show_board_views` but not `manage_board_views`:
  `modules/boards/app/seeders/common.yml:39-41`.
- UI: the create control and the row's Delete are offered only with `manage_board_views`
  (`modules/boards/app/components/boards/add_button_component.rb:36`,
  `modules/boards/app/components/boards/row_component.rb:77`); a list title is editable only when
  the Board is manageable (`board-list.component.ts:271-276`).
- Create: an unauthorised `POST /api/v3/grids` fails validation, not authorization — 422, pinned by
  `modules/boards/spec/requests/api/v3/grids/grids_resource_spec.rb:434-456`.
- Delete: the grids API answers a user who may not edit the Board as if it did not exist — 404
  (`modules/grids/app/controllers/api/v3/grids/grids_api.rb:75-81`).
- Rename: a list is a public Query (`modules/boards/app/services/boards/base_create_service.rb:59`);
  changing one without permission is `error_unauthorized` (`app/contracts/queries/update_contract.rb:57-60`),
  which the API answers with 403 (`lib/api/errors/error_base.rb:48-49`).
