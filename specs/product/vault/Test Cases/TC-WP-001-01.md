## Preconditions

- Demo Project exists

## Steps

1. Open Work Packages list
2. Click 'Create new Work Package'
3. Select Type 'Task'
4. Enter Subject only, leave all other fields blank
5. Click Save

## Expected result

Work Package is created; detail view shows auto-generated ID, Status='New', Priority='Normal'.
