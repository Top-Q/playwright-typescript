## Preconditions

- Work Package A has a child Work Package C that is not Closed ^open-child

## Steps

1. Open Work Package A
2. Choose Delete from its menu
3. Try to confirm the deletion without ticking the acknowledgement

## Expected result

The confirmation dialog says A has one child and warns "All child work packages and their descendants will also be recursively deleted." Delete stays disabled until "I acknowledge that ALL descendants of the listed work packages will be recursively removed." is ticked. A and C still exist.
