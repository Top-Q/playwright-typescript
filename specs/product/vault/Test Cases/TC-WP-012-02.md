## Preconditions

- Multiple Work Packages exist, user has edit permission on all

## Steps

1. Select multiple Work Packages
2. Choose bulk 'Change Assignee' to a given Member
3. Confirm

## Expected result

All selected Work Packages' Assignee field updates to the chosen Member.
