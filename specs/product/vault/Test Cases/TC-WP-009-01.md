## Preconditions

- A Work Package exists
- Logged in as a user with edit permission

## Steps

1. Change the Work Package's Priority field
2. Save
3. Open the Activity tab

## Expected result

An entry appears showing the old and new Priority values, the acting user, and a timestamp.
